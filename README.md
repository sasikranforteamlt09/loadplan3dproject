# LoadPlan 3D

ระบบช่วยวางแผนการจัดวางพัสดุขึ้นพื้นที่บรรทุกของรถบรรทุก ด้วยขั้นตอนวิธีจุดสุดขอบ (Extreme Point)
ผลงานจาก **ปริญญานิพนธ์ สาขาเทคโนโลยีโลจิสติกส์ คณะวิทยาศาสตร์และศิลปศาสตร์
มหาวิทยาลัยเทคโนโลยีราชมงคลอีสาน นครราชสีมา ปีการศึกษา 2569**

เว็บนี้เป็นหน้าเว็บแบบสแตติกล้วน คำนวณทั้งหมดในเบราว์เซอร์ของผู้ใช้
**ไม่มีเครื่องแม่ข่าย ไม่มีฐานข้อมูล ไม่มีระบบล็อกอิน และไม่เก็บข้อมูลไว้ในเครื่อง**

---

## โครงสร้างหน้าเว็บ

| เส้นทาง | หน้าที่ |
|---|---|
| `/` | หน้าแรก — ที่มาของปัญหา วิธีใช้ 3 ขั้นตอน หลักการคำนวณ ภาพหน้าจอจริง และรหัสคิวอาร์ |
| `/app` | ตัวเครื่องมือ 3 ขั้นตอน — เลือกรถ → นับพัสดุ → แผนการจัดวาง |

ใช้ `react-router-dom` แบบ **BrowserRouter** (ไม่มี `#` ในที่อยู่เว็บ)
และมีไฟล์ `public/_redirects` ที่เขียนว่า `/*  /index.html  200`
เพื่อให้ Cloudflare Pages ส่งทุกเส้นทางกลับมาที่ `index.html` ผู้ใช้จึงเปิด `/app` ตรง ๆ หรือกดรีเฟรชได้

## วิธีใช้งานสำหรับผู้พัฒนา

ต้องมี Node.js รุ่น 18 ขึ้นไป

```bash
npm install        # ติดตั้งไลบรารี (ครั้งแรกครั้งเดียว)
npm run dev        # เปิดเซิร์ฟเวอร์สำหรับพัฒนา แล้วเปิด http://localhost:5173
npm test           # รันชุดทดสอบแกนคำนวณ 29 ชุด ต้องได้ 0 ทุกรายการ
npm run build      # สร้างไฟล์สำหรับเผยแพร่ลงโฟลเดอร์ dist/
npm run preview    # ลองเปิดไฟล์ในโฟลเดอร์ dist/ ก่อนนำขึ้นจริง
```

## วิธีนำขึ้น Cloudflare Pages ผ่าน GitHub

1. สร้างคลังเก็บโค้ด (repository) ใหม่บน GitHub แล้วส่งโค้ดชุดนี้ขึ้นไป
   ```bash
   git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อคลัง>.git
   git branch -M main
   git push -u origin main
   ```
2. เข้า [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
3. เลือกคลังเก็บโค้ดที่เพิ่งส่งขึ้นไป แล้วตั้งค่าดังนี้
   - Framework preset: **Vite**
   - Build command: `npm run build`
   - Build output directory: `dist`
   - Node version (ตัวแปรสภาพแวดล้อม `NODE_VERSION`): `20`
4. กด **Save and Deploy** รอสักครู่จะได้ที่อยู่เว็บรูปแบบ `https://<ชื่อโครงการ>.pages.dev`
5. นำที่อยู่นั้นไปใส่ในตัวแปร `DEPLOY_URL` ในไฟล์ `src/config.ts` แล้ว commit + push อีกครั้ง
   รหัสคิวอาร์ในหน้าแรกจะถูกสร้างใหม่ให้ตรงกับที่อยู่จริงโดยอัตโนมัติตอน build
6. ครั้งต่อ ๆ ไปเพียง push ขึ้น GitHub ระบบจะ build และเผยแพร่ให้เองทุกครั้ง

## หมายเหตุ

- ขนาดตู้ของ "รถ 4 ล้อ ตู้ทึบ" ในระบบยังเป็น **ค่าสมมติ** รอค่าที่วัดจริงจากหน้างาน ห้ามนำตัวเลขไปใส่ในเล่ม
- แกนคำนวณใน `src/lib/pack.ts` ให้ผลลัพธ์ตรงกับ `pack.js` รุ่นวานิลลาทุกตัวเลข (ตรวจสอบแล้ว 29 ชุดข้อมูล)
- ไม่มีการเก็บความลับ (secret) หรือคีย์ใด ๆ ในคลังเก็บโค้ดนี้
